# Swiggy-Order-Revenue-Analysis-using-SQL

## Overview

This project focuses on analyzing a food delivery platform's data to derive actionable business insights. The goal is to simulate real-world decision-making scenarios using SQL by evaluating performance across orders, revenue, customer behavior, restaurant performance, and ratings.

Instead of treating this as a technical exercise, this project is structured around real business questions that a food delivery company would ask to improve growth, optimize operations, and enhance customer experience.

---

## Objectives

- Measure overall business performance using key KPIs
- Analyze trends across time (monthly, quarterly, yearly)
- Identify high-performing cities and regions
- Evaluate restaurant and cuisine performance
- Understand customer spending behavior
- Analyze rating distributions to assess service quality

---

## Business Impact

This analysis helps stakeholders:
- Identify revenue-driving regions and cuisines
- Optimize restaurant partnerships
- Understand customer price sensitivity
- Detect demand patterns for better planning
- Improve customer satisfaction using rating insights
